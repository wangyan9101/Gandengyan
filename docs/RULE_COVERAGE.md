# 规则覆盖与验证范围

运行 `npm run check` 执行规则源码严格类型检查与全部 Vitest 测试。本表描述行为覆盖，不代表已经测量语句/分支覆盖率，也不代表 Cocos、微信或联机环境已验证。

| 规则/不变量 | 对应测试文件 | 关键案例 |
| --- | --- | --- |
| Card 模型与实体身份 | card.test.ts、hand.test.ts | 54/108 张、每副四花色 13 点数及两王、跨副同花色同点数不撞 ID、伪造 ID/点数拒绝 |
| Fisher–Yates | deck.test.ts | 下界 0、接近 1、n−1 次调用、空/单元素、非法随机值、种子复现、输入不变 |
| 2～8 人发牌 | deck.test.ts | 两种副数 × 每个人数 × 每个庄家位置；6/5 张及余牌数，顺序与守恒 |
| 配置 | config.test.ts、game.test.ts | 人数与封顶边界、炸弹集合、长度限制、稀疏数组、版本、复制冻结 |
| 单张/对子 | hand.test.ts | 同点数、双副同花色对子、相邻/跳级、A、特殊 2、2 后不可普通压制 |

| 3～8 张炸弹 | hand.test.ts、game.test.ts | 各个张数、禁用大小、张数优先、同张数点数、同强度拒绝、跨普通牌型压制 |
| 王/癞子 | hand.test.ts、game.test.ts | 单王与纯王组牌拒绝、对子/顺子/连对/炸弹补牌、多解释及声明、无中生有改天然点数拒绝 |

| 非法动作不修改 | game.test.ts | 非本人牌、重复 ID、空命令/伪造字段、过期版本、非法组合/声明/压制、原状态引用及内容保持 |

测试夹具 `helpers.ts` 中的 scenario 创建完整且守恒的中途状态，未分配牌显式放入弃牌；不把它作为公开游戏 API。LCG 仅用于测试随机复现，不是未来服务端的安全随机实现。

本地 UI 另需基于真实 Creator 类型声明执行 typecheck:client，并在编辑器/浏览器/手机上按 LOCAL_PLAY 验证。纯会话整局测试不会模拟真实触摸、渲染、屏幕布局或构建管线。

## 仍需人工决定

1. 仅剩王且必须自由领出时如何继续或结束；当前暂停明确保留此缺口，没有补造胜负规则。
2. 确认本版本顺子/连对长度与相邻接牌、炸弹张数优先及软硬炸同等的默认方案。
3. 确认每轮所有玩家从上手起各补至多一张的默认补牌方案。
4. 后续会话层的换庄、超时、托管与断线策略。

用户在本次会话已确认：王不可单出、仅搭自然牌；输家损失封顶且赢家收入可超封顶。不能再次把这两项当作未决规则，也不能引入收费或可兑现积分。
